# Carola Castiglione, Private Chef

Sito vetrina per Carola Castiglione, private chef a Roma: cene private, tavoli
d'affari e corsi di cucina.

**Online:** https://gmagistr.github.io/carola-castiglione/

## Cosa c'e' dentro

| File | Descrizione |
|---|---|
| `index.html` | Il sito, in un unico file: font, immagini e stili sono incorporati, nessuna dipendenza esterna |
| `biglietti-da-visita.html` | Anteprima dei biglietti da visita, con funzione di stampa |
| `stampa/` | File per la tipografia e sorgenti del marchio |

## Cartella stampa

- `carola-biglietto-{fronte,retro}[-600dpi].psd` file di stampa a livelli, 85x55 mm con 3 mm di abbondanza
- `carola-biglietto-{fronte,retro}[-600dpi].xcf` versione GIMP con testi modificabili e monogramma vettoriale
- `monogramma-cc-{scuro,chiaro}.svg` il marchio in vettoriale, scalabile senza perdita
- `build_cards.py` rigenera i biglietti dopo aver cambiato i contatti
- `fonts/` Cabinet Grotesk e Satoshi, i caratteri del progetto

## Identita'

- Colori: verde bosco `#1B2621`, ambra `#D9A344`, osso `#EDE8DB`, lino `#F4EEE1`
- Caratteri: Cabinet Grotesk per i titoli, Satoshi per il testo
- Marchio: due C che nascono dai bordi di un piatto visto dall'alto
